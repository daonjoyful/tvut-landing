사이트 수익·방문 대시보드

여러 사이트를 운영하는 계정 소유자가 자신의 광고 수익과 방문 통계를 한 화면에서 확인하는 Windows용 개인 대시보드입니다.

이 페이지는 앱 소개와 데이터 처리 안내입니다. 실제 대시보드와 계정별 수익 자료는 운영자의 컴퓨터에서만 열립니다.

주요 기능

  • 연결한 AdSense 계정별 예상 수익과 사이트별 실적 확인
  • 접근 권한이 있는 GA4 속성의 사용자·세션·페이지 조회수 확인
  • 유입 경로와 조회가 많은 페이지 확인
  • 필요한 계정을 추가하고, 대시보드가 열려 있는 동안 주기적으로 보고서 갱신

Google 연결 방식

Google의 계정 선택 및 동의 화면에서 본인 계정을 직접 승인합니다. 앱은 AdSense 데이터 보기와 Analytics 데이터 확인·다운로드 권한만 요청합니다. 광고 설정, 지급 정보, Analytics 설정을 수정하는 권한을 요청하지 않습니다.

개인용 로컬 앱

일반 방문자를 위한 회원가입이나 공개 통계 조회 기능은 제공하지 않습니다. 설치된 앱은 해당 컴퓨터의 루프백 주소에서 실행되며, 이 웹페이지에는 Google 연결 토큰이나 보고서 데이터를 전송하지 않습니다.

데이터 처리 방식은 개인정보처리방침에서, 사용 범위는 이용 안내에서 확인할 수 있습니다. 문의는 Google 동의 화면에 표시된 앱 지원 연락처를 이용해 주세요.
