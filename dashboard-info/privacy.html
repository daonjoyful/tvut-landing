접근하는 Google 데이터

계정 소유자의 동의를 받아 AdSense 계정·사이트 목록과 예상 수익, 페이지뷰, 광고 노출·클릭 등 집계 실적을 조회합니다. Google Analytics에서는 계정·속성·웹 스트림 설정과 사용자 수, 세션, 페이지 조회수, 유입 경로 등 보고서 데이터를 조회합니다. 앱 연결을 유지하기 위한 OAuth 인증 정보도 처리합니다.

이용 목적과 권한

데이터는 소유자의 사이트 운영 현황을 대시보드에 표시하고 보고서를 갱신하는 데만 사용합니다. Google 권한은 adsense.readonly 및 analytics.readonly입니다. Google 계정 비밀번호를 앱에서 입력받거나 저장하지 않습니다.

저장 장소와 보호

보고서와 내보낸 파일은 사용자의 컴퓨터에 저장합니다. OAuth 연결 정보는 Windows 사용자 계정에 연결된 DPAPI로 암호화해 보관합니다. 보고서 파일 자체는 일반 로컬 파일이므로 운영체제 계정과 파일 접근 권한으로 관리해야 합니다. 앱 서버는 해당 컴퓨터의 루프백 주소에서만 접속을 받습니다.

공유 및 전송

인증과 보고서 조회를 위해 Google의 공식 API와 통신합니다. 앱이 조회한 비공개 보고서나 인증 정보를 이 공개 안내 웹사이트로 보내지 않습니다. 데이터를 판매하거나 광고 타기팅, 신용 평가, 범용 AI 모델 학습에 사용하지 않습니다. 제3자 분석 서비스로 보고서 데이터를 전송하지 않습니다. 운영자가 직접 CSV를 내보내거나 공유하는 경우는 운영자가 관리합니다.

보관과 삭제

로컬 보고서, 내보낸 파일 및 연결 정보는 운영자가 삭제할 때까지 보관될 수 있습니다. Google 계정의 서드 파티 연결 관리에서 앱 권한을 철회할 수 있습니다. 권한 철회 후에도 이미 저장된 로컬 보고서는 자동 삭제되지 않습니다. 앱을 종료하고 설치 폴더의 data·private 폴더 및 별도로 내보낸 파일을 삭제하면 해당 로컬 자료를 제거할 수 있습니다.

Google 데이터의 제한적 사용

Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책과 그 제한적 사용 요구사항을 따릅니다. 사람이 데이터를 확인하는 경우는 계정 소유자가 앱 사용·문제 해결을 위해 명시적으로 허용한 범위로 제한합니다.

이 안내 페이지

이 앱 안내 페이지에는 별도의 광고나 Analytics 추적 코드를 넣지 않습니다. 웹 호스팅 제공자가 페이지 제공과 보안을 위해 일반적인 접속 기록을 처리할 수 있습니다.

문의 및 변경

문의는 Google 동의 화면에 표시된 앱 지원 연락처를 이용해 주세요. 데이터 처리 방식이 변경되면 이 페이지와 앱 내 안내를 함께 갱신합니다.
